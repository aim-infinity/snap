# Snap: landing page

Source for https://aim-infinity.github.io/snap/, the landing page for Snap, a Chrome extension that captures, annotates and exports screenshot flows locally.

Static HTML and CSS with no scripts or third-party requests. Built from the private extension repository; edit there and republish.
